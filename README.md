# 旅する韓国語 🇰🇷

初心者向け・旅行実践会話に特化したiPhone用PWAの試作版です。

## 入っている機能
- 買い物／コスメ・洋服、カフェ・飲食、交通、ホテルのフレーズ
- 韓国語・カタカナ発音・日本語訳
- 単語ごとの意味
- 韓国語音声読み上げ（端末・ブラウザに韓国語音声がある場合）
- フレーズ保存（端末内）
- シーン別会話シミュレーション
- ミニ確認テスト
- PWAオフラインキャッシュ（初回アクセス後）

## iPhoneで使う方法
1. このフォルダの中身をHTTPS対応のWebホスティングにアップロードします（例：GitHub Pages、Netlify等）。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン →「ホーム画面に追加」。
4. ホーム画面の「旅韓国語」アイコンから起動します。

※PWAのインストールにはHTTPS配信が必要です。`file://`で開いただけではホーム画面アプリになりません。
※音声読み上げはブラウザの音声合成機能を利用します。韓国語音声の有無やオフライン再生可否はiOSの設定・環境に依存します。
※これは初期プロトタイプです。カタカナは発音の目安で、正確な発音は音声で確認してください。


## v2：教材の追加・編集
- 画面下部「＋ 教材」からフレーズや複数ターンの会話練習を追加・編集・削除
- ChatGPT作成のJSONを貼り付けて一括取り込み
- JSONの書き出し・ファイルからの読み込み
- 追加教材はブラウザのlocalStorageに保存。iPhoneとPC間の自動同期はありません

### ChatGPTに教材を依頼する例
「旅する韓国語v2の取り込み用JSONを作って。コスメ店のフレーズを10件と会話練習を2本。形式は `{"phrases":[{"cat":"shopping","kr":"...","kana":"...","jp":"...","words":[["単語","意味"]]}],"scenarios":[{"title":"...","turns":[{"q":"...","opts":["正解","不正解"],"correct":0,"why":"..."}]}]}` にして」

### GitHub Pagesで更新
既存リポジトリのルートにある `index.html`、`sw.js`、`manifest.webmanifest` を新しいファイルで上書きしてコミットしてください。更新が反映されない場合はSafariを再読み込みしてください。
